# Package and document installation

## Goal
Make the service and both extensions installable and maintainable.

## Expected outcome
Documented builds and installation steps work on the user's Mac, Windows PC, and VPS.

## Tasks
- Package the Go service with persistent SQLite storage and configurable HTTPS deployment.
- Provide an optional Docker Compose and Caddy setup.
- Document backups, restore, upgrades, migrations, and credential revocation.
- Produce a Brave extension build and a Safari app build.
- Document Safari signing or local-testing requirements and extension permissions.
- Verify fresh installation, pairing, restart, and upgrade on the target devices.
