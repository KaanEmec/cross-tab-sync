# Detect local browser activity

## Goal
Identify likely device switches without treating sync as user activity.

## Expected outcome
A debounced activity signal can request automatic takeover.

## Tasks
- Combine validated focus, activation, tab creation, and navigation signals.
- Suppress activity generated by startup restoration and extension-applied changes.
- Distinguish a new interaction from a browser simply remaining focused.
- Define takeover debounce and manual Hand over suppression until fresh local activity.
- Preserve the current tab and window focus during background application.
- Verify both browsers remaining open and switching between them repeatedly.
